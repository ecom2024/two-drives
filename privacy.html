Конфиденциальность

Эта политика описывает, как приложение «Два диска» обрабатывает данные подключённых аккаунтов Google.

Какие данные нужны

Адрес аккаунта позволяет выбрать нужный Диск. Доступ на просмотр используется для поиска и чтения файлов. Доступ к Google Таблицам используется для чтения значений и формул, проверки расчётов и внесения запрошенных изменений.

Обработка и хранение

Команды выполняются на Mac и обращаются к Google по HTTPS. Разрешения для повторного входа хранятся в Связке ключей macOS. Результаты операций могут сохраняться в локальных рабочих файлах и, если выбрана синхронизируемая папка, на соответствующем Диске.

При выполнении задачи через ChatGPT данные, которые прочитала команда и передала в чат, обрабатывает также ChatGPT с учётом настроек аккаунта. Владелец управляет историей чатов и сохранёнными файлами отдельно. Публичные страницы приложения на GitHub Pages содержат только описание и эту политику.

Использование данных

Данные Google используются для выполнения запросов владельца. Приложение не продаёт их и не использует для рекламы. На этих страницах нет форм входа или аналитики приложения. Для посещений сайта действуют также правила конфиденциальности GitHub.

Отзыв доступа и удаление копий

В настройках подключений Google можно выбрать приложение и отозвать его разрешение на дальнейшие обращения. Для каждого аккаунта это делается отдельно. Владелец может удалить сохранённые отчёты на Mac и историю соответствующих чатов через настройки ChatGPT. Для связи с владельцем приложения используйте адрес поддержки в окне согласия Google.
